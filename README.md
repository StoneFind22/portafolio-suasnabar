## 📌 Descripción

Plataforma web desarrollada en **Next.js 16 (App Router) + React 19 + Tailwind CSS v4** bajo la metodología **DreamDev** y el sistema de diseño visual **DreamDesign**.

El portafolio está estructurado en dos secciones principales:
1. **Entregas de la Asignatura Suasnabar**: Compilación completa de laboratorios, benchmarks comparativos y la evaluación parcial, todos vinculados a sus respectivos repositorios en GitHub.
2. **Ecosistema Global de Repositorios**: Catálogo interactivo de **26 repositorios públicos** (sistemas web, proyectos académicos UNCP, herramientas y prácticas de laboratorio) con búsqueda instantánea y filtros dinámicos.

## 🚀 Instalación y Ejecución Local

```bash
# Clonar el repositorio
git clone https://github.com/UNCP-PROJECTS/portafolio-suasnabar.git

# Entrar al directorio
cd portafolio-suasnabar

# Instalar dependencias con pnpm
pnpm install

# Modo desarrollo con Turbopack
pnpm dev

# Compilar para producción
pnpm build

# Iniciar servidor de producción
pnpm start
```

## ☁️ Despliegue en Vercel (Staging)

El proyecto está optimizado para despliegue instantáneo en Vercel sin configuración de dominios:
1. Conectar el repositorio `UNCP-PROJECTS/portafolio-suasnabar` en el dashboard de Vercel.
2. Framework preset detectado automáticamente como **Next.js**.
3. Se generará una URL de staging `https://portafolio-suasnabar.vercel.app`.
